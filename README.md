# 你适合几月离职

像素风二选一测试。答完 5 道题，告诉你该在几月离职、去哪座城市。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 全部代码。单页应用，无依赖、无构建 |
| `assets/封面.webp` | 封面页（进入应用的第一屏，853×1844） |
| `assets/故事A.webp` | 剧情第一页（同一张夜 office，没有气泡） |
| `assets/故事B.webp` | 剧情第二页（带空白气泡，气泡里逐句出字） |
| `assets/选择性别.webp` | 选性别页（整页设计图，两块卡片热区叠在上面） |
| `assets/主页女.webp` | 女生版题卡背景（选「女生」后加载） |
| `assets/主页男.webp` | 男生版题卡背景（选「男生」后加载） |

## 流程

封面 →「开始测试」→ 剧情A（轻触 1 次）→ 剧情B（轻触 6 次，气泡逐句出字）→ 选性别 → 5 道题 → 结果页

剧情B 的气泡文字顺序：`……` → `受够了` → `要不离职吧？` → `冷静一下？` → `现在吗` → `我想想`。进页先给第一句，之后每触一次出下一句（触发 5 次走完六句），最后一句之后再触一次进选性别页。

## 本地打开

双击 `index.html` 即可。或在当前目录起个静态服务：

```bash
python3 -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`

## 逻辑

- 封面页只有一个热区（图里画好的「开始测试」），点掉封面层进剧情
- 剧情两页都是整页图，点任意位置推进；剧情B 的气泡文案在 `BUBBLE_LINES` 里，改数组即可
- 选性别页也是整页图，`#pickM` / `#pickF` 两块热区对准图里的两张卡片
- 5 道题（每题 2 个选项）→ 结果页
- Q1–Q4 从 16 座城市里锁定 1 座；Q5 决定出「订票」还是「躺平」结局
- 无随机数、无权重打分：同一套答案永远同一结果，可对答案
- 4 层二分题上限 16 个结果，所以城市定 16 座，每座都真实可达
- 城市 → 最佳月份为固定表，12 个月全覆盖

## 改文案

全部在 `index.html` 的 `<script>` 里：

| 变量 / 函数 | 内容 |
|---|---|
| `CITIES` | 城市 → 最佳月份 + 理由 |
| `Q1` `Q2` `Q3` | 前三题题面与选项（Q2、Q3 按分支各存一套） |
| `Q4` | 8 个包内的二选一 |
| `Q5` | 分叉题，决定结局走哪条线 |
| `countdown()` | 结果页倒计时（按系统当前月份实时算） |
| `leaveApplyText()` | 「X 月中旬提离职」那一行 |
| `buildResult()` | 结果页的版式与标签文案 |
| `BUBBLE_LINES` | 剧情B 气泡里的六句话，按顺序出 |
| `drawHint()` | 剧情页底部「轻触继续」的提示 |
| `BTN` | 封面上「开始测试」按钮的像素框（改封面图才需要动） |

封面、两张剧情图、选性别页上的**所有文字和图形都是画在图片里**的，不是网页文字。要改这些页的文案，得重出对应的图；换图后若热区位置变了，同步改 `BTN`（封面）或 `#pickM` / `#pickF` 的 CSS 坐标（选性别页）。

## 实现说明

- 背景是固定 **853×1844** 的像素画。所有文字按这个基准定位，用 CSS 变量 `--u = 屏幕宽 / 853` 换算，任意屏幕等比缩放，不写死像素。
- 六张背景图合计 **578 KB**（WebP q70），整包 < 650 KB。图是首屏加载的大头，**再加图之前先想清楚体积**。压缩命令是 `cwebp -q 70 -m 6 -sharp_yuv`，`-sharp_yuv` 相比默认能再省 10% 左右且边缘更干净。**不要再往下压**——q60 只省 27KB，但暗部开始出色块。
- 封面图、两张剧情图、选性别页都与题卡画布**同为 853×1844**，比例一致，所以在舞台里都是**满屏**的，不留白也不裁切。
- 封面的点击热区不是写死的百分比，而是运行时按实际缩放和偏移算出来的（`layoutCover()`），所以换屏幕比例也不会点偏；手指热区在按钮外再扩 26px（图片像素）。实测封面按钮为 x 227–621 / y 1556–1670，热区取 x 220–636 / y 1550–1678（853×1844 基准），中心落在屏高 87% 处。
- 剧情页的热区是整页（点哪都行），不用算。
- 选性别页的热区用 `--u` 直接写坐标：男生卡 x 40–812 / y 633–1026，女生卡 x 40–812 / y 1071–1466（实测卡片边框，两张各 772×394）。
- 气泡文字的中心是 **(194, 658)**（气泡白区实测 x 49–339 / y 597–718），字面高 28。最长的「要不离职吧？」成品宽约 168px，气泡在该高度可用宽约 280px，留边充足。
- 文字不是图片，是 canvas 实时渲染的像素字：系统宋体 28px 光栅化 → 阈值二值化 → 最近邻放大 → `image-rendering: pixelated`。笔画边缘是硬边，不会糊在像素背景上。
- 字色 `#4F1E0E`；字面高：题号 32 / 题干 47 / 选项 42，均取自原图实测。
- 中文断行做了标点优先：贪心铺满后回退到最近的标点断行，不会出现「什么」被劈成两行。
- 字体依赖系统宋体。macOS / iOS 用 Songti SC，Android 回退到 Noto Serif CJK，字形会略有差异。
- 男版背景的底部按钮比女版低 34px，点击热区已分别校准。
